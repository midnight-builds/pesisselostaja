# Pesä Ysit YouTube Share Message Format

Use this format when sharing scheduled YouTube links for **multiple games on the same day**.

## Rule
Send **one unified message** instead of separate per-game blurbs.

## Preferred wording
Start with a short one-line intro that names the day context and team group.

Example intro:
`Kuvaan tänään E-tyttöjen kilpapelit Kuusankoskella.`

Then list each game in chronological order.
For each game include:
- kickoff time as `Klo HH:MM`
- matchup on one line
- YouTube link on the next line
- narrated YouTube link on the next line labeled `YouTube selostettu:` when available
- Pesistulokset link on the next line labeled clearly for result tracking

## Template
```text
Kuvaan tänään <joukkue/ryhmä> <paikkakunnalla/tapahtumassa>.

Klo <HH:MM> <Kotijoukkue> - <Vierasjoukkue>
YouTube: <youtube-link>
YouTube selostettu: <narrated-youtube-link>
Tulospalvelu: <pesistulokset-link>

Klo <HH:MM> <Kotijoukkue> - <Vierasjoukkue>
YouTube: <youtube-link>
YouTube selostettu: <narrated-youtube-link>
Tulospalvelu: <pesistulokset-link>
```

## Notes
- Use this grouped format only when there are multiple games to share together.
- Keep the order chronological.
- Keep wording compact and copy-paste friendly.
- If there is only one game, the single-game share format can still be used.
- Keep team names readable; avoid unnecessary extra framing.
- Pesistulokset link must be included specifically for result tracking.
- If narrated version exists, include it directly under the normal YouTube link.
